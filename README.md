# jd_lib

## in progress
- `jd_debug`: debugging tools
- `jd_gfx`: graphics tools

## ideas
- `jd_memory`: safe, efficient memory management
- `jd_error`: unified error handling w/ context
- `jd_types`: type safety, input validation
- `jd_serialize`: serialization, parsing for json, yaml
- `jd_threads`: threading, sync utils
- `jd_datastruct`: basic data structures (lists, maps, queues)
- `jd_test`: unit testing, assertion macros
- `jd_net`: network utils
- `jd_files`: file ops
- `jd_input`: unified input handling (keyboard, mouse, controllers)
- `jd_math`: math
- `jd_cli`: cli tooling utilities
